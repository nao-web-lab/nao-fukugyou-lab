ココナラの招待コードの使い方｜1,000円分ポイントをもらう手順と条件・注意点

更新日：2026-11-03 ／ 執筆者：NAO

PRこの記事には、ココナラの招待プログラムによる紹介リンクが含まれます。リンク経由で登録された場合、当サイト運営者に特典が付与されることがありますが、登録・利用料金が変動することはありません。

ココナラには、招待コードを使って会員登録すると、登録した側（紹介された人）に特典がもらえる「友達紹介キャンペーン」があります。この記事では、ココナラ公式ヘルプで確認した内容にもとづいて、特典の内容・もらうための条件・手順・注意点を整理します。ココナラそのものの使い方や、スキルを売る方法はスキル販売サービスで得意を収入に変える方法で解説しています。

確認日と出典 この記事の特典の内容・条件は、2026年11月3日にココナラ公式ヘルプ「友達紹介キャンペーンについて」で確認したものです。ココナラは事前の予告なく特典を中止したり内容を変更することがあると案内しているため、登録前に最新の内容を公式ヘルプで確認してください。

紹介された人がもらえる特典

＜紹介されたお友達（招待コードで登録した人）＞ 4営業日以内に、1,000円分の期間限定ポイントが付与されます。このポイントの有効期限は、取得日から3か月です。期限を過ぎると失効します。

ポイントの有効期限が3か月と短めなので、登録だけして使わないままにならないよう、「何を依頼するか」を先に考えておくと無駄がありません。

特典をもらうための条件（3つすべて必要）

  1. 招待URLまたは招待コードを使って会員登録すること。紹介者から届いた招待URLか招待コードを利用します。
  2. 会員登録から7日以内に招待コードが登録されていること。会員登録から8日目以降は、招待コードの登録ができなくなります。
  3. 双方の電話番号認証（SMS認証）が完了していること。認証にはSMSを受信できる携帯電話が必要です。

招待コードを使う手順

パターン1：招待URLから登録する（いちばん簡単）

  1. 紹介者から届いた「招待コードURL」を開き、会員登録をします。
  2. 登録後に届く認証用メールのURLを開きます（Googleなど各種アカウント連携で登録した場合は、認証用メールは届きません）。
  3. ユーザー情報を入力すると、電話番号の認証画面が開きます。招待コードは自動で入力されるため、入力は不要です。
  4. 認証用の携帯電話番号を入力して「認証番号を送る」を選び、SMSで届いた6ケタの認証番号を入力して「認証する」を選びます。
  5. 認証が完了すると、4営業日以内に期間限定ポイントが付与されます。

パターン2：招待コードを手入力する（アプリで登録した場合など）

  1. 先に会員登録を済ませます。
  2. マイページ（画面右上のアイコン）から「友達招待」を選び、「友達を招待する」ページを開きます。
  3. ページ下部（アプリの場合は「招待された人」タブ）の「招待コードを入力する」を選び、招待コードを入力して「登録する」を選びます。
  4. 以降は電話番号認証（パターン1の手順3以降）と同じです。

手入力できるのは、会員登録から7日間までです。8日目以降は入力できなくなるので、登録したらその日のうちに済ませるのがおすすめです。

ココナラの招待リンクを開く 招待コード：QDPWMK（このリンクから登録すると、招待コードは自動で適用されます）

注意しておきたいこと

注意点
  • 招待コードを利用できるのは1人1回、会員登録から7日間までです。
  • 自分で発行した招待コードを、自分で使うことはできません。
  • 招待コードを使うには、SMSを受信できる携帯電話が必要です。
  • 紹介された人が、自分の電話番号ですでに友達紹介キャンペーンの特典を受け取っている場合は、一定期間、期間限定ポイントが付与されません。
  • 不正と判断された場合は、ポイント付与の対象外になったり、アカウント停止などの措置がとられることがあります。特典目的だけの複数登録などは行わないでください。
  • キャンペーンは、事前の予告なく中止・変更されることがあります。

紹介する側にも特典があります

ココナラの公式ヘルプによると、紹介した人（紹介者）にも、紹介された人が3か月以内に初回購入して該当のトークルームがクローズした場合などの条件を満たすと、2,000円分の期間限定ポイントが付与されます。紹介者が出品者の場合は、条件を満たした初回取引の販売手数料が無料になる特典もあります。詳しい条件は公式ヘルプで確認してください。当サイトの招待リンクから登録いただいた場合、当サイト運営者にもこの特典が付与される場合があります。

登録したあとの次の一歩

  • ココナラで自分のスキルを売ってみたい方 → スキル販売サービスで得意を収入に変える方法
  • まず案件を受けて経験を積みたい方 → クラウドソーシングで在宅ワークを始める手順
  • 売上が出たあとの税金が気になる方 → 副業の確定申告・税金の基礎知識（年間20万円ルールなど）
