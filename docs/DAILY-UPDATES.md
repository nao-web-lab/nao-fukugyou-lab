# 毎日の更新ルール・バックログ

目的: 訪問者を増やし、アフィリエイト・紹介リンクが自然にクリックされるサイトにする。
1日1テーマずつ、**正確さを最優先**で改善する。

## 守ること
- お金・税金・制度・手数料の記述は、公式の一次情報（国税庁・金融庁・消費者庁・公式サイト等）で確認してから書く。確認できなければ書かない。数字は作らない。
- 「必ず稼げる」などの断定、収入保証はしない。
- アフィリエイト・紹介リンクのある記事は、冒頭 `pr-note` と末尾 `disclosure-note` を入れ、リンクには `rel="sponsored"` を付ける。
- 新しいアフィリエイトプログラム、計測タグ（GA4等）、外部サービスの追加は、なおとさんの承認なしに行わない。
- スクリーンショットにTikTokのプロフィール写真・ニックネーム等の個人情報を写さない。
- 記事を追加/変更したら、`articles.html` のカード、`index.html`、`sitemap.xml`、関連記事リンク、`dateModified` を揃える。
- コミットメッセージは日本語。末尾に `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`。

## AI使用量の最適化（なおとさん指示 2026-10-21）
- 作業に必要なファイルだけ読む。サイト全体を毎回解析しない（バックログの対象記事と、変更に関わるカード/サイトマップだけ）。
- 前回までに検証済みで、今回の変更の影響を受けない項目は再検証しない。
- 長いログやソースを出力しない。報告は要点のみ。
- 軽い作業（リンク確認・日付更新など）は軽量な手段で。難しい判断だけ重く考える。
- Codexなど別AIに同じ調査を重複して依頼しない。
- 新しい有料API・課金サービスは事前承認なしに使わない。
- テストは変更範囲に応じて（記事1本の変更ならその記事と関連リンクのみ）。大きな変更やデザイン変更の前後は全体確認。

## 1回の作業の流れ
1. `git pull` → 副業ニュースの自動更新が動いているか確認（Actionsの最新実行）。
2. 下のバックログから**1つ**選んで実施（上から順）。
3. ローカルで表示確認（リンク切れ・画像・横スクロールなし）。
4. コミット → push → 下の「実施ログ」に1行追記。
